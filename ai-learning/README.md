# AI learning track

1. [`01_glm_repo_review.md`](01_glm_repo_review.md): a correctness review of `vukrosic/glm-5.3-flash-from-scratch`, and how its slides were built.

To add your Zotero textbooks, export the library as BibTeX/CSV into this folder, and the curriculum can be mapped onto the books you already own.
